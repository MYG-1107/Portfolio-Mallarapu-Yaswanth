ZenTimer — Focus & Mindfulness Timer

A local-first timer for focus sessions, mindfulness routines and repeatable multi-stage activities.

Project overview

ZenTimer reduces the setup friction around a simple countdown and lets users build repeatable routines. It includes quick-start templates as well as controls for custom stages and repeat loops.

The problem it addresses

Browser timers can be interrupted by tab throttling, mobile background policies and notification permissions. The application makes these limitations visible instead of presenting a browser timer as a guaranteed native alarm.

Engineering approach

A Web Worker handles timer scheduling using timestamps. Session history, routines and reflections are stored locally in IndexedDB. The app uses browser audio, notifications, Media Session and Screen Wake Lock capabilities when available, and provides an app-shell cache for offline access after installation.

Key capabilities

  • Single timers and multi-stage routines with repeat loops.
  • Morning Reset, Pomodoro x4 and Deep Work templates.
  • Procedural ambient audio, chimes, voice completion and silent visual completion.
  • Local history, streaks, heatmaps, reflection notes and Markdown/CSV export.
  • Custom MP3/WAV bells, a guided breathing visual and PWA installation metadata.

Scope and limitations

ZenTimer is a browser application, not a native safety-critical alarm service. Browser, operating-system, power-saving and permission policies may affect audio, notifications, wake lock and background execution. Do not rely on it as the sole timer for medical, emergency or industrial processes.
