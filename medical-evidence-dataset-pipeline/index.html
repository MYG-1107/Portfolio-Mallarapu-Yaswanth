Multi-Source Medical Claim & Evidence Dataset Pipeline

A reproducible data pipeline that ingests open-access reference material, filters declarative medical claims and enforces a minimum evidence requirement.

  • AI & data engineering

Project overview

This repository produces a curated evidence dataset for AI trust infrastructure and model evaluation in the health and medicine domain. Its focus is data provenance and filtering rather than a public end-user application.

The problem it addresses

Question-style prompts, duplicate statements and weakly supported records make evidence datasets difficult to use consistently for evaluation.

Engineering approach

The pipeline collects data from multiple reference repositories, filters records to declarative factual claims, normalises text across sources, removes duplicates and exports a JSONL dataset. Its quality rule requires at least four distinct evidence entries for each accepted claim.

Key capabilities

  • Multi-source ingestion, including WikiDoc and MedQA as described in the repository.
  • Filtering that removes question-style and QA-format items.
  • Cross-source text normalisation and deduplication.
  • A minimum of four distinct evidence items per accepted claim.
  • Dataset report and manual quality-audit files for traceability.

Scope and limitations

The repository README reports 22,624 raw records and 10,852 usable claims (3,399 attributed to WikiDoc and 7,453 to MedQA). These are the repository's reported pipeline metrics, not a claim that the data is clinically validated or suitable for diagnosis or treatment.
