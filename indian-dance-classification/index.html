AI Model for Indian Classical Dance Classification

A computer-vision project that classifies eight Indian classical dance forms from images using Microsoft Azure Custom Vision.

  • Project case study
  • Machine learning & computer vision
View project document ↗All projects

Project overview

The portfolio describes a computer-vision model that recognises eight classical Indian dance forms from single images and exposes predictions through a web application.

The problem it addresses

Recognising a dance form from a single image requires extracting visual patterns that distinguish pose, costume and other visible cues across different dance styles.

Engineering approach

The project used Microsoft Azure Custom Vision for image classification and connected predictions to a web interface through REST API endpoints.

Key capabilities

  • Classification across eight Indian classical dance forms, as stated in the portfolio.
  • Image-based inference using Azure Custom Vision.
  • A web application interface for submitting images and receiving predictions.
  • REST API integration between the application and model service.

Scope and limitations

Model accuracy depends on dataset coverage, image quality, training labels and the similarity of real-world inputs to training examples. The linked PDF is the available project document; no matching public source-code repository is linked from the portfolio.
