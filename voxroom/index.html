VoxRoom — Instant Browser Audio Rooms

A room-based voice collaboration app using WebRTC for peer-to-peer audio and Socket.IO for signalling between browser participants.

Project overview

VoxRoom is designed for quick voice conversations without forcing participants to create accounts or install a native application. A host creates a room and shares its room ID or invitation link.

The problem it addresses

Browser voice calls need a reliable signalling path to exchange connection information while keeping the actual audio stream peer-to-peer where possible.

Engineering approach

The repository separates the frontend from a Node.js and Socket.IO backend. The backend creates and validates room identifiers, manages current room participants and relays WebRTC signalling messages. Once peers establish a connection, audio flows directly between browsers.

Key capabilities

  • Create a room with an automatically generated room ID or join an existing room.
  • Guest nicknames, participant list and mute/unmute controls.
  • Raise-hand events and copy/share invitation links.
  • WebRTC offer, answer and ICE candidate signalling through Socket.IO.
  • Responsive interface, dark/light theme and rate-limited room endpoints.

Scope and limitations

Room state is managed in memory by the repository's room manager, so this architecture does not promise durable rooms across server restarts. Real-world connectivity depends on browser permissions, ICE/STUN/TURN configuration and network conditions. The repository README does not provide a verified public production URL.
