Bachelor Finance Manager

A local-first shared-expense application for roommates, students and shared flats, with deterministic balances and suggested settlements.

Project overview

Bachelor Finance Manager helps small groups record shared expenses and understand who should reimburse whom. The current release is a browser-only application: each workspace stays in the browser profile where it was created, and no account or cloud synchronisation is required.

The problem it addresses

Shared expense tools can produce confusing balances when participants, filters or rounding are handled inconsistently. This project focuses on predictable calculation behaviour and clear, exportable records.

Engineering approach

The settlement logic is separated into a pure domain module and uses integer paise arithmetic with deterministic remainder allocation. The interface reads the active workspace from browser storage and renders filter-aware summaries. CSV serialisation is kept separate from the UI.

Key capabilities

  • Create multiple named workspaces in one browser profile.
  • Add roommates and record expenses by date, category and payer.
  • Choose the exact participants for each expense and calculate suggested transfers.
  • Filter by month, category and search term; KPIs and CSV exports follow the active filter.
  • Print reports or save them as PDF, and export or restore a complete workspace as JSON.

Scope and limitations

This release has no application server, database, account system or cross-device sync. Data in localStorage is not encrypted secure storage and can be cleared with browser data. Keep a JSON backup for important records. Suggested transfers are recommendations only; the app does not execute payments.
