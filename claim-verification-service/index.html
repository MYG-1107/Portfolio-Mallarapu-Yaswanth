Claim Verification Service

An evidence-first FastAPI microservice that retrieves relevant source passages and evaluates incoming claims against indexed reference material.

Project overview

Claim Verification Service is a small retrieval-based verification API. Reference text is ingested into a local ChromaDB vector store, then an incoming claim is compared with relevant retrieved passages.

The problem it addresses

A useful verification result needs to show what evidence was retrieved, not just return a label with no explanation.

Engineering approach

The service uses all-MiniLM-L6-v2 sentence embeddings to retrieve related excerpts. Strict Pydantic schemas define the request and response, and a configurable threshold controls the deterministic VERIFIED or UNVERIFIED response along with a confidence score and source excerpt.

Key capabilities

  • Ingest reference documents through a versioned API endpoint.
  • Retrieve the closest source excerpts for a submitted claim.
  • Return a VERIFIED or UNVERIFIED label, confidence score and evidence excerpt.
  • Persist the local ChromaDB collection between service restarts.
  • Run in a local Python environment, Docker container or GitHub Codespaces.

Scope and limitations

The returned label is bounded by the quality, coverage and freshness of the indexed sources and the configured similarity threshold. It is an evidence-retrieval aid, not a guarantee that a claim is universally true or false. No public hosted API URL is listed in the repository.
