Project overview

EJITE is an academic journal platform developed within the SITER Academy work described in the portfolio. It supports manuscript submission and peer-review workflow management, with a MongoDB-backed publishing data layer.

The problem it addresses

A journal platform has to organise author submissions, reviewer activity, editorial workflows and published article records while remaining usable for authors, reviewers and administrators.

Engineering approach

The portfolio records work across ASP.NET Core controller-based APIs and Minimal APIs, PHP, MongoDB Atlas, responsive JavaScript interfaces and automated OpenAPI documentation. It also records multi-server administration and production maintenance across SITER Academy and conference domains.

Key capabilities

  • Manuscript submission and peer-review workflow management.
  • Journal content and academic-record management.
  • Responsive interfaces using modern JavaScript and Tailwind CSS.
  • API integration supported by Swashbuckle / OpenAPI documentation.
  • Production deployment and administration across institutional websites.

Scope and limitations

The portfolio records a 50,000+ academic-record environment and a 25% query-response improvement during the described work. These are project-reported figures, not independently benchmarked measurements in this case-study page.
