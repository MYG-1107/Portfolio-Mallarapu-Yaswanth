FinanceFit — Financial Health Score & Budget Planner

A browser-based financial health check that turns a few user-entered numbers into a score, budget breakdown and practical action plan.

Project overview

FinanceFit is designed to help students, working adults and young professionals understand a snapshot of their financial health without first connecting a bank account or creating a profile.

The problem it addresses

Personal finance can feel difficult to start. FinanceFit uses a short guided assessment to make savings rate, debt pressure, emergency-fund coverage and budget allocation easier to understand.

Engineering approach

The front end calculates the core result in the browser and displays the score, 50/30/20 budget analysis, savings goals and debt-payoff estimates. The repository also contains an optional Express API for sharing a score snapshot; the README describes those snapshots as expiring after seven days.

Key capabilities

  • A 0–100 financial-health score based on financial indicators.
  • Budget breakdown and comparison with the 50/30/20 guideline.
  • Savings-goal timeline and debt-payoff calculator.
  • Prioritised actions based on the values entered by the visitor.
  • Dark-mode support, local auto-save and share/copy actions.

Scope and limitations

The browser calculation is a planning aid, not regulated financial advice. The README describes the sharing API as an optional extension; the front end works without sending the user's financial inputs to a server. The sample backend stores shared score snapshots in memory and is not a durable production database.
