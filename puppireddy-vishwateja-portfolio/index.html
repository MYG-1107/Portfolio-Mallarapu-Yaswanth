Project overview

The repository contains a portfolio website for Puppireddy Vishwateja. Its content includes a professional summary, work experience, engineering projects, technical competencies, education, credentials and contact information.

Project objectives

A developer's portfolio should connect skills to concrete work. This site uses project descriptions and experience sections to present technical capabilities across full-stack development, generative AI and computer vision.

Implementation approach

The repository uses a static HTML page with separate CSS and JavaScript files. The page provides responsive navigation and separate sections for experience, projects, skills, education and contact.

Website sections and capabilities

  • Professional summary and work-experience section.
  • Engineering project descriptions, including a finance manager, Azure AI dance classifier and GenAI document QA/RAG pipeline.
  • Technical competencies across backend, frontend, AI and developer tools.
  • Education, certifications and honours.
  • Contact information.

Scope and attribution

This website presents Puppireddy Vishwateja's professional profile, not the owner of this portfolio. Project and career details are included as published in that profile repository.
