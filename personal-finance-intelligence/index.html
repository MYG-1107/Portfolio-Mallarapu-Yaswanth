Project overview

Personal Finance Intelligence is a privacy-focused finance application for recording transactions, managing budgets and savings goals, reviewing recurring costs and exploring planning insights from financial history.

The problem it addresses

A useful finance dashboard has to combine everyday bookkeeping with understandable forecasting and recurring-cost signals, without hiding where calculations and data are handled.

Engineering approach

The repository separates the Blazor WebAssembly client, ASP.NET Core API, shared request/response contracts, ML services and automated tests. Entity Framework Core persists application data in SQLite by default. ML.NET services support category prediction, anomaly scoring and SSA cash-flow forecasting.

Key capabilities

  • Manual income and expense entry, recurring transactions, search, filters and CSV export.
  • Natural-language Smart Add and ML-assisted transaction category prediction.
  • Budget dashboards, savings goals, recurring-payment and subscription analysis.
  • Cash-flow forecasting, forecasted month-end balance, burn-rate views and anomaly scoring.
  • Shared budget workspaces with Viewer and Contributor roles, PDF reports and interactive charts.

Scope and limitations

The repository README describes a development password-reset flow that returns a reset token in the response; a production deployment needs secure email delivery and must not expose reset tokens in the UI. No public live deployment URL is listed in the repository, so this page links to the source repository rather than presenting a demo as available.
