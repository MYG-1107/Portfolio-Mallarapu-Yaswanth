Learn Norwegian — Bokmål Practice

A static learning site for practising Norwegian Bokmål with translation, speech features, phrasebooks, pronunciation guidance and vocabulary activities.

Project overview

Learn Norwegian is a browser-based learning resource centred on Norwegian Bokmål. Its pages provide sentence practice and structured learning material for beginners and independent learners.

The problem it addresses

Language practice benefits from more than a single translation box: learners also need pronunciation support, useful phrases and ways to revisit vocabulary over time.

Engineering approach

The site is delivered as static HTML, CSS and JavaScript through GitHub Pages. Vocabulary progress and learning streaks are stored locally in the browser. Speech recognition and text-to-speech are optional browser capabilities, and selected static pages can be cached for offline use after the first successful load.

Key capabilities

  • Sentence practice and translation interface.
  • Everyday phrasebook, beginner guide and pronunciation guide.
  • Topic-based flashcards with answer reveal, shuffle, speech playback and known/review tracking.
  • Short multiple-choice quiz, best-score tracking, daily word and study streak.
  • Optional offline access for selected static pages and optional weather information.

Scope and limitations

There is no user account, backend or cross-device progress synchronisation. The repository documents the translation integration as a public Google Translate endpoint pattern rather than a supported production API, and speech features vary by browser and installed voices. Visitors should not submit sensitive text.
